# Google Play Store Listing: Hindi
This file covers all the store listing texts for Zashi's presence in the Google Play Store.

*Note: Only the texts under the titles are meant to be translated. 

## Store presence

### App name

Zashi: Zcash वॉलेट

### Short description

Zashi एक Zcash वॉलेट है जो आपकी ट्रांज़ैक्शन और मैसेज हिस्ट्री को प्राइवेट रखता है।

### Full description

Zashi एक Zcash वॉलेट है जो आपकी ट्रांज़ैक्शन और मैसेज हिस्ट्री को प्राइवेट रखता है।

Zcash के आविष्कारक Electric Coin Co. (ECC) द्वारा बनाया और संभाला गया, Zashi $ZEC इस्तेमाल करने का सबसे आसान तरीका है।

Zashi Zcash वॉलेट क्यों इस्तेमाल करें?
* आप ZEC और प्राइवेट मेमो भेज और प्राप्त कर सकते हैं। (अपनी माँ को Zashi करें! अपने बरिस्ता को Zashi करें!)
* यह भरोसेमंद और तेज़ है, और इसमें सिंक से पहले खर्च करने की सुविधा है। (सिंक पूरा होने से पहले ही फंड उपलब्ध रहता है।)
* UI पूरी तरह नया है, सरल और साफ़।
* यह Sapling और Orchard पूल का समर्थन करता है, साथ ही Unified पते का भी, जो एक ही तरह का पता है और सभी Zcash पूल में काम करता है, transparent और शील्डेड दोनों में।
* इसमें यूज़र सपोर्ट और डेवलपर फीडबैक की सुविधा पहले से मौजूद है।
